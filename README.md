# 🎮 Demon Slayer C++ Game

A 2D game inspired by Demon Slayer, developed in C++ using Object-Oriented Programming.

## 🚀 Features
- Player movement (run, jump, attack)
- Enemy system (demons with behaviors)
- Level progression
- Sound effects and background music
- Collision detection

## 🛠 Technologies
- C++
- OOP (Classes, Inheritance)
- SFML (if you used it — confirm)
- File handling

## ▶️ How to Run
1. Compile:
   g++ main.cpp -o game
2. Run:
   ./game
